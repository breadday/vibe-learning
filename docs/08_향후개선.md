# 향후 개선

## 코드에서 확인되는 미완성 연결

- 검수 콘텐츠를 계속 추가하고 콘텐츠별 등록 영상 연결 기준을 정교화
- `LearningWorkspace`의 정적 문구를 콘텐츠 데이터 기반으로 일반화
- 실제 재생 위치를 추적해 `playbackSeconds`와 메모 타임스탬프에 반영

## 기존 계획 문서의 후보 기능

다음은 기존 개발 가이드와 설계에 향후 단계 또는 제외 범위로 적힌 내용이며 현재 구현 기능이 아닙니다.

- 영상 수 확대와 콘텐츠 승인·숨김·재생성
- YouTube 메타데이터 및 자막 수집
- 선택 구간 AI 분석과 캐시
- 최신 웹 자료 검색과 자동 수집
- 퀴즈, 마인드맵, 반복 복습, 통계
- 로그인, 데이터베이스
- 서버 기반 계정 동기화

AI 기능을 도입한다면 계획 문서의 `videoId + transcriptHash + promptVersion + model` 캐시 기준과 선택 구간만 전송하는 경계를 먼저 검토해야 합니다. 현재는 모델, API, 프롬프트 파일, AI 실패 처리 코드가 없습니다.

## 개선 전 확인할 사항

- 서버 저장 추가 시 “브라우저에만 저장” 안내와 개인정보 범위가 달라집니다.
- 스키마 버전을 올릴 때 IndexedDB와 JSON 백업 마이그레이션이 필요합니다.
- 자동 메타데이터나 AI 결과에는 출처, 검증 상태, 실패 시 TODO 기준이 필요합니다.
- 현재 Vercel 운영 URL은 `docs/05_배포및운영.md`에 기록되어 있습니다. 배포 환경의 API 키 제한, Lighthouse 측정값, Analytics 수집 상태는 지속적으로 확인해야 합니다.
