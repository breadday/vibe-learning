# 설치 및 실행

## 준비 사항

- Node.js와 npm
- E2E 테스트용 Playwright Chromium

GitHub Actions는 Node.js 24를 사용합니다. `package.json`은 Node.js `>=20`을 요구합니다.

## 설치와 개발 서버

```powershell
cd C:\workspaceLocal\vibe-learning
npm ci
npx playwright install chromium
# 프로젝트 루트의 로컬 환경변수에 YOUTUBE_API_KEY 설정
npm run dev
```

로컬에서는 `http://localhost:3000`으로 접속하세요. `127.0.0.1`과
`localhost`는 브라우저 저장소가 서로 분리되므로, 앱은 `127.0.0.1`로
접속한 경우 같은 포트의 `localhost` 주소로 자동 이동합니다.

E2E 테스트는 `localhost:3300`에서 개발 서버를 자동 실행합니다. 이 서버는 개발 서버(3000)와 출력 폴더(`.next-e2e`)까지 분리해 동시에 실행해도 간섭하지 않습니다.

## 품질 검사

```powershell
npm run lint
npm run typecheck
npm test
npm run build -- --webpack
npm run test:e2e
```

각 명령은 ESLint, TypeScript 무출력 검사, Vitest, Next.js 프로덕션 빌드, Playwright Chromium 테스트를 실행합니다.

## 프로덕션 실행

```powershell
npm run build -- --webpack
npm run start
```

## 환경변수

제목 자동 조회를 사용하려면 Google Cloud 프로젝트에서 YouTube Data API v3를 활성화하고 API 키를 발급한 뒤, 프로젝트 루트의 커밋되지 않는 로컬 환경변수 파일에 `YOUTUBE_API_KEY`를 설정해야 합니다. 실제 키는 문서나 Git에 기록하지 마세요. 키의 API 제한은 YouTube Data API v3만 허용하도록 설정하는 것을 권장합니다.

키가 없거나 조회가 실패해도 제목을 직접 입력해 영상을 등록할 수 있습니다. 테스트와 빌드는 외부 API와 실제 키 없이 동작합니다.

| 이름 | 용도 |
|---|---|
| `YOUTUBE_API_KEY` | 서버 Route Handler의 YouTube 영상 제목 조회 |
| `NEXT_DIST_DIR` | Next.js 출력 폴더 변경, 기본값 `.next`; E2E에서는 `.next-e2e` |
| `CI` | Playwright 재시도 횟수와 `test.only` 금지 여부 결정 |

현재 앱은 개인·로컬 사용을 우선하지만 Vercel 배포를 지원합니다. 공개 배포 시 인증 없는 제목 Route Handler가 YouTube API 할당량 남용 경로가 될 수 있으므로, 배포 환경에서 요청 제한과 API 키 제한을 별도로 검토해야 합니다. 배포 URL과 운영 주의사항은 `docs/05_배포및운영.md`를 참고하세요.
