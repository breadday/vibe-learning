# 문제 해결

## 등록 버튼이 활성화되지 않음

HTTPS 주소와 학습 제목이 모두 필요합니다. 지원 호스트는 `youtube.com`, `www.youtube.com`, `m.youtube.com`, `youtu.be`이며 영상 ID는 11자리여야 합니다. `/live/` 주소는 현재 지원하지 않습니다.

## 이미 등록된 영상이라고 표시됨

같은 YouTube 영상 ID는 한 번만 저장됩니다. `기존 영상으로 이동`을 눌러 저장된 상세 화면을 엽니다.

## 저장 또는 복원이 실패함

브라우저가 `localStorage`를 막았거나 저장 용량이 부족할 수 있습니다. 저장 설정과 여유 공간을 확인합니다. 가져오는 파일은 `schemaVersion: 1`의 유효한 학습 백업이어야 합니다.

## 저장한 데이터가 사라짐

데이터는 계정이나 서버가 아닌 현재 브라우저에만 있습니다. 브라우저 데이터 삭제나 다른 브라우저·기기에서는 자동으로 이어지지 않습니다. 홈의 JSON 내보내기와 가져오기를 사용합니다.

## 영상 또는 썸네일이 보이지 않음

네트워크나 콘텐츠 차단 설정에서 `youtube-nocookie.com` 또는 `i.ytimg.com` 접근을 막고 있는지 확인합니다. 앱은 YouTube API로 대체 정보를 가져오지 않습니다.

## 상세 화면에서 영상을 찾지 못함

URL의 영상 ID가 현재 브라우저 저장소에 없으면 나타나는 정상 안내입니다. 홈으로 돌아가 영상을 등록합니다.

## 테스트 관련 문제

- E2E 브라우저가 없으면 `npx playwright install chromium`을 실행합니다.
- E2E는 3100 포트와 `.next-e2e` 출력 폴더를 사용합니다.
- CI와 같은 빌드 확인은 `npm run build -- --webpack`을 사용합니다.
- 실행하지 않은 검사는 통과했다고 판단하지 않습니다.
