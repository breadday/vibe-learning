# 2026-09-01 프로젝트 문서화

## 작업 목적

현재 저장소의 코드, 설정, 콘텐츠, 테스트, CI 구성을 근거로 Obsidian용 프로젝트 문서를 갱신했습니다.

## 확인한 범위

- `app/`, `components/`, `lib/`, `content/`, `e2e/`
- `package.json`, TypeScript·Next.js·Vitest·Playwright 설정
- `.github/workflows/ci.yml`
- 기존 개발 가이드와 기능 설계 문서
- `.env*` 파일 및 환경변수 참조 여부

## 주요 확인 결과

- 현재 핵심 기능은 YouTube URL 수동 등록, 브라우저 저장, 상태·개인 메모, JSON 백업·복원입니다.
- 백엔드, 데이터베이스, 뉴스 수집, AI API, 자동 배포는 없습니다.
- 검수 콘텐츠와 전용 학습 UI 코드는 있으나 현재 라우트에 연결되지 않았습니다.
- 런타임 사용자 데이터의 스키마 버전과 검수 콘텐츠의 스키마 버전은 모두 1이지만 서로 다른 구조입니다.
