## 이 영상을 볼 가치

ChatGPT에 원격 MCP 서버를 연결해 파일 읽기·수정, 명령 실행, 배포까지 수행하는 코딩 에이전트형 흐름을 14분 안에 보여줍니다. 구현 시연보다 중요한 학습 포인트는 **모델이 어떤 도구와 권한을 받으면 무엇을 할 수 있는지**입니다. 다만 기능과 플랜 정책이 빠르게 변하고 시스템 변경 권한의 위험도 크므로, 그대로 설치하는 안내서가 아니라 구조와 보안 경계를 이해하는 사례로 보는 것이 좋습니다.

## 핵심 요약

- 일반 채팅은 코드를 답변할 수 있지만 작업 파일과 실행 환경에 자동으로 접근하지는 않습니다.
- MCP 서버는 모델이 외부 컴퓨터의 데이터와 도구를 사용할 수 있게 연결합니다.
- 파일 읽기·쓰기와 명령 실행 도구가 있으면 코딩 에이전트와 비슷한 작업 흐름을 만들 수 있습니다.
- 영상은 별도 클라우드 컴퓨터에서 블로그 구축, 데이터베이스 설정, 배포를 시연합니다.
- 비밀번호 노출이나 취약한 비밀번호 변경처럼 민감한 요청은 차단될 수 있습니다.
- 모델의 자체 차단만 믿지 말고 서버와 도구에 최소 권한을 적용해야 합니다.
- 코드는 작성으로 끝나지 않고 실행, 화면 확인, 수정, 재검증을 반복해야 합니다.
- 화면 캡처와 브라우저 도구는 실제 결과를 확인하는 데 사용할 수 있습니다.
- 자동 작업과 스케줄은 권한 범위가 넓어질수록 오작동의 영향도 커집니다.
- 실제 연결 전 현재 플랜 지원 범위와 공식 보안 안내를 다시 확인해야 합니다.
