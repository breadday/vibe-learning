# 주요 기능

## 1. YouTube 영상 등록

홈에서 HTTPS YouTube 주소를 입력합니다. 허용 주소는 `youtube.com`, `www.youtube.com`, `m.youtube.com`, `youtu.be`의 일반 영상, Shorts, embed 형식입니다. 11자리 영상 ID를 검사한 뒤 표준 watch URL로 변환합니다.

유효한 주소는 공개 썸네일과 영상 ID를 미리 보여 주고, 서버 Route Handler가 공식 YouTube Data API로 영상 제목만 조회해 입력란을 채웁니다. 자동 제목은 자유롭게 수정할 수 있으며 조회 실패 시 직접 입력해 등록할 수 있습니다. 같은 영상 ID가 이미 저장되어 있으면 새 항목을 만들지 않고 기존 상세 화면으로 이동하도록 안내합니다.

## 2. 개인 학습 목록

- 마지막으로 열었던 미완료 영상 우선의 `이어서 학습`
- 등록일 기준 최근 영상 3개
- 수정일 기준 내림차순 전체 목록
- 확인 대화상자를 거친 영상 삭제

## 3. 영상 학습과 상태 관리

상세 화면은 `youtube-nocookie.com` iframe으로 영상을 재생합니다. 상태는 학습 전, 학습 중, 완료 중에서 직접 선택하며 변경 내용은 즉시 브라우저에 저장됩니다.

현재 상세 화면에는 재생 위치를 감지하거나 복원하는 기능이 없습니다. 데이터의 `playbackSeconds`는 존재하지만 UI에서 갱신되지 않아 새 메모의 타임스탬프도 현재 구현상 기본값 0초입니다.

## 4. 개인 메모

영상별로 최대 500개의 메모를 저장할 수 있고, 메모 하나는 공백을 제외해 1~2,000자입니다. 추가·수정·삭제를 지원하며 삭제 전 확인을 받습니다. 메모는 같은 브라우저의 IndexedDB에만 남습니다. 저장 성공 시 `BroadcastChannel`로 다른 탭에 변경 사실을 알립니다.

## 5. JSON 백업과 복원

- 내보내기 전에 v1 스키마를 검증하고 날짜가 포함된 JSON으로 다운로드
- 가져오기 전에 JSON 문법과 데이터 구조 검증
- 영상 수, 메모 수, 중복 영상 수 미리보기
- 현재 데이터를 교체하는 `덮어쓰기`와 합치는 `병합` 제공
- 병합 시 같은 `youtubeId`는 `updatedAt`이 더 최신인 영상 전체를 유지

## 6. 검수 콘텐츠 기반 학습 UI

검수된 영상 2건의 JSON과 MDX를 `/learn/first-video`, `/learn/second-video`에서 제공합니다. 구간 이동·실습 단계·복사 블록·개념·경고·출처를 표현하며, 콘텐츠는 Zod 스키마로 엄격히 검증됩니다. 첫 영상은 3단계, 두 번째 영상은 4단계 학습 흐름을 사용합니다.

## 현재 없는 기능

뉴스 수집, 자동 자막 수집, AI 분석·요약, 카테고리 분류, 중요도 평가, 로그인, 서버 저장, 데이터베이스는 구현되어 있지 않습니다. 서버 API는 YouTube 제목 조회 경로 하나만 제공합니다.
