# 프로젝트 개요

## 프로젝트 목적

`vibe-learning`은 YouTube 영상을 단순히 보고 끝내지 않고 개인 학습 자료로 남기기 위한 웹 앱입니다. 사용자가 YouTube 주소와 학습 제목을 직접 입력하면 영상, 학습 상태, 메모를 한곳에서 관리할 수 있습니다.

현재 구현은 로그인이나 서버 없이 한 브라우저에서 사용하는 로컬 우선 방식입니다.

## 현재 제공하는 기능

- YouTube 일반 영상, 단축 URL, Shorts, embed 주소 검사 및 표준 URL 변환
- 사용자가 정한 제목으로 영상 등록, 중복 등록 방지
- 이어서 학습, 최근 등록, 전체 목록 표시와 영상 삭제
- 학습 상태를 `학습 전`, `학습 중`, `완료`로 변경
- YouTube 개인정보 강화 모드 플레이어 표시
- 영상별 개인 메모 추가·수정·삭제
- 학습 데이터를 JSON으로 내보내기, 미리보기 후 병합 또는 덮어쓰기
- 검수된 정적 학습 콘텐츠 1건과 콘텐츠 스키마 보유

## 기술 스택

| 영역 | 실제 사용 기술 |
|---|---|
| Web | Next.js 16 App Router, React 19, TypeScript 5 |
| UI | CSS, Tailwind CSS 4 PostCSS 플러그인 |
| 콘텐츠 | JSON, MDX |
| 검증 | Zod 4, JSON Schema Draft 2020-12 생성 |
| 저장 | 브라우저 `localStorage` |
| 테스트 | Vitest, Testing Library, Playwright |
| CI | GitHub Actions, Node.js 24 |
| Backend / AI / Database | 현재 없음 |

## 주요 디렉터리

```text
vibe-learning/
├─ app/                 Next.js 라우트와 전역 스타일
│  └─ videos/[id]/      저장된 영상 상세 화면
├─ components/          등록, 목록, 상세, 백업 및 학습 UI
├─ lib/
│  ├─ content/          정적 콘텐츠 스키마와 로더
│  ├─ storage/          브라우저 저장 및 백업 로직
│  └─ youtube/          YouTube URL 파서
├─ content/             검수 콘텐츠 JSON과 MDX
├─ e2e/                 Playwright 사용자 흐름 테스트
├─ docs/                계획 및 Obsidian 프로젝트 문서
└─ .github/workflows/   GitHub Actions 검증 워크플로
```

## 현재 상태

홈(`/`)과 저장 영상 상세(`/videos/[id]`)이 실제 사용자 흐름입니다. `content/first-video.json`, MDX, `LearningWorkspace` 등 검수 콘텐츠용 구현도 존재하지만 현재 App Router 페이지에서는 연결해 표시하지 않습니다.

README 파일은 없습니다. 기존 `docs/`의 초기 범위와 실제 코드가 다른 부분은 현재 코드를 기준으로 정리했습니다.
