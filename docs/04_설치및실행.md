# 설치 및 실행

## 준비 사항

- Node.js와 npm
- E2E 테스트용 Playwright Chromium

GitHub Actions는 Node.js 24를 사용합니다. `package.json`에는 별도의 `engines` 제한이 없습니다.

## 설치와 개발 서버

```powershell
cd C:\workspaceLocal\vibe-learning
npm ci
npx playwright install chromium
npm run dev
```

E2E 테스트는 `127.0.0.1:3100`에서 개발 서버를 자동 실행합니다.

## 품질 검사

```powershell
npm run lint
npm run typecheck
npm test
npm run build -- --webpack
npm run test:e2e
```

각 명령은 ESLint, TypeScript 무출력 검사, Vitest, Next.js 프로덕션 빌드, Playwright Chromium 테스트를 실행합니다.

## 프로덕션 실행

```powershell
npm run build -- --webpack
npm run start
```

## 환경변수

저장소에 `.env*` 파일은 없습니다. 코드에서 확인되는 환경변수는 다음뿐입니다.

| 이름 | 용도 |
|---|---|
| `NEXT_DIST_DIR` | Next.js 출력 폴더 변경, 기본값 `.next`; E2E에서는 `.next-e2e` |
| `CI` | Playwright 재시도 횟수와 `test.only` 금지 여부 결정 |

API 키나 비밀값을 요구하는 기능은 없습니다.
